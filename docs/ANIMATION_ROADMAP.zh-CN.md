# dsh-whale-animation 动画设计与路线图

## v0.5.0 视觉纠偏

本版本的核心目标不是继续堆叠特效，而是先统一鲸鱼主体。v0.4.0 的程序化轮廓存在明显的普通鱼类特征：背鳍突出、尾柄过短、叉尾刚硬、头身比例偏小，且多个状态主要依赖整体旋转而非躯干形变。

v0.5.0 改为中轴线驱动模型：沿身体纵向采样中心线和法向量，再通过尾部权重、传播相位、弯曲项和呼吸项构造上下轮廓。头部保持相对稳定，尾部振幅最大，动作会沿尾柄和躯干连续传播。

## 不可破坏约束

1. `dive` 必须逐字节对应 v0.3 提交 `65e1205d1fbf4b01997e6dfc099103b0f9717e37` 的历史资产。
2. `classic` 必须逐字节对应首发提交 `95b06e3f0e6ea817d25858eb29f7064a233b3c65` 的历史资产。
3. 新状态不得重新引入背鳍、鲨鱼式轮廓或短而僵硬的鱼尾。
4. 特效只能辅助表达状态，不能遮挡鲸鱼头部、眼睛和嘴线。
5. 运行时继续保持离线、纯视觉和完整生命周期清理。

## 状态动作语言

- **Sonar**：低频游动，声呐弧线从吻部扩散。
- **Tool Run**：高频行波和摆尾，速度线集中在尾部后方。
- **Stream**：中频游动，粒子沿吻部前方输出。
- **Calm**：低振幅呼吸、尾部漂移与单次克制眨眼。
- **Retry**：短促 C 形回弹和注意力射线，不使用卡通对话框。

## 后续方向

- 接入 DSH 稳定阶段事件后，用真实阶段替换兼容性定时轮播。
- 增加可配置的显示尺寸、轮播间隔和状态开关，但保持默认零配置。
- 在不改变主体轮廓的前提下，探索水面、潜深、完成和成功等状态。
- 为生成器增加轮廓相似度快照和关键帧接触表回归测试。
