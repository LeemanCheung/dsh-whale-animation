# dsh-whale-animation 动画扩展方案

## 目标

将原先“单个 WebP 永久循环”的装饰插件升级为可持续扩展的动画系统，同时保持三条底线：运行时不联网、不读取用户内容、不侵入 Harness 的业务状态与交互。

## v0.4.0 已落地

### 1. 动画资产矩阵

| 状态 | 视觉语义 | 触发方式 |
|---|---|---|
| Deep Dive | 破水、翻滚、重新下潜 | 默认播放列表；思考/推理类关键词 |
| Sonar | 向前传播的声呐波 | 默认播放列表；搜索/检索类关键词 |
| Tool Run | 高频摆尾、速度线、工作粒子 | 默认播放列表；工具/执行/构建/测试类关键词 |
| Stream | 类 Token 粒子连续输出 | 默认播放列表；生成/撰写/流式输出类关键词 |
| Calm | 低幅呼吸、气泡上浮 | 默认播放列表；等待/排队类关键词 |
| Retry | 轻微摆动与注意提示 | 仅错误、失败、重试类关键词 |

每套动画使用 352 × 352 透明画布、48 帧、40 ms/帧，单循环 1.92 秒；同时生成对应 PNG 静态帧。

### 2. 双轨动画导演

当前 Harness 在完整运行回合中持续显示同一个 `Deep diving...` 文案，因此仅按文字分类无法让新增动画真正出现。v0.4.0 采用双轨策略：

1. 普通情况下，每 9 秒按 `dive → sonar → work → compose → idle` 自动轮换。
2. 当未来版本或定制界面提供可识别状态文案时，关键词状态立即覆盖定时播放列表。
3. 错误/重试状态优先级最高，不会进入普通播放列表。
4. 减少动态效果模式下停止轮换并固定为默认静态帧。

### 3. 集成策略

- 使用 `role="status"` 与 `_turnStatus` 组合定位，降低仅依赖哈希类名的脆弱性。
- 只占用目标元素的 `::after`，不再清空 `::before`。
- 通过 `data-dsh-whale-state` 切换 CSS 中的内嵌 data URL，不产生运行时资源请求。
- MutationObserver 处理 Harness 局部重绘；定时器只负责每秒判断一次状态，不参与逐帧绘制。
- dispose 时清理样式、定时器、观察器和所有插件属性。

### 4. 验证门禁

- 所有 WebP 的 RIFF/WEBP 格式、帧数、帧时长与循环时长。
- 所有 PNG 的文件签名、大小与 SHA-256。
- manifest、源文件和 `lib/client.js` 内嵌 data URL 三方一致。
- 状态关键词解析、9 秒轮换、错误覆盖、reduced-motion 固定、挂载与卸载。
- README 头图、动画预览、状态画廊的尺寸、帧数和本地链接。
- Chromium 中的真实 CSS 伪元素渲染与深色模式截图烟测。

## 后续路线

### v0.5：真实运行阶段事件

当 DSH Client Runtime 暴露稳定的 turn/tool/stream 阶段事件后，优先从“定时导演”升级为“真实阶段驱动”，保留定时播放列表作为兼容回退。

### v0.6：轻量配置

考虑提供仅本地的构建配置：动画尺寸、轮换间隔、启用状态、默认状态和紧凑布局；不引入账号、网络或持久化权限。

### v0.7：资产扩展包

将更多鲸类或季节主题做成可选资产包，主包继续保持体积上限和零配置体验，避免默认 Bundle 无限制膨胀。
